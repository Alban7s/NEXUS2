    What is accepted

    • Static sites with a root index.html
    • React/Vite and other Node projects with a build script
    • Up to 100 MB

    What is rejected

    • Corrupt, empty or encrypted archives
    • Paths that escape the folder (../)
    • Symlinks, nested archives, .git
    • .env files and private keys
    • ZIP bombs and huge file counts

    Uploaded code is built inside Docker, never run on the NEXUS server itself.

    Developers don’t sign in to GitHub here. The administrator connects one repository to Jenkins once; Jenkins keeps the credentials.
